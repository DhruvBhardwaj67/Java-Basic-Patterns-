# ☕ Java Pattern Programs

Welcome to my **Java Pattern Programs** repository!

This repository contains different pattern-printing programs implemented using Java. These programs are designed to strengthen programming fundamentals, improve logical thinking, and develop a better understanding of loops.

## 🎯 Purpose of This Repository

The main goal of this repository is to:

- Strengthen understanding of `for`, `while`, and nested loops.
- Understand how inner and outer loops work together.
- Improve logical thinking and problem-solving skills.
- Learn row and column-based pattern logic.
- Build a strong foundation in Java programming.

## 📚 Patterns Covered

### ⭐ Star Patterns
- Square Pattern
- Triangle Pattern
- Inverted Triangle Pattern
- Pyramid Pattern
- Diamond Pattern

### 🔢 Number Patterns
- Number Triangle
- Inverted Number Pattern
- Pyramid Number Pattern

### 🔤 Alphabet Patterns
- Alphabet Triangle
- Alphabet Pyramid

## 🛠️ Technologies Used

- **Language:** Java
- **IDE:** VS Code

## 💡 What I Learned

By practicing these patterns, I am improving my understanding of:

- Basic loops and nested loops.
- Loop iteration and execution flow.
- Rows and columns logic.
- Conditional statements inside loops.
- Breaking complex problems into smaller steps.
